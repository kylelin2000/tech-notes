# tech-notes

個人技術學習筆記，多數內容由 AI agent 協助蒐集公開資料後整理成中文摘要。各篇筆記附有來源索引，細節請以原始來源為準。

## 工具

撈資料、整理資料的程式都放在 [tools/](tools/README.md)（抓取腳本、各主題來源表、筆記檢查、agent-runner）；主題資料夾只放筆記。整理流程與各工具說明見 [tools/README.md](tools/README.md)。
